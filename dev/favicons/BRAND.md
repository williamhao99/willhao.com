# Brand Character

Right-facing blue pixel chess knight. 32x32 base, nearest-neighbor upscaled.

## Colors

- Highlight: `#1177cc`
- Body: `#0055aa`
- Shadow: `#004488`
- Deep shadow: `#003366`
- Outline: `#0f172a` (the on-page hero sprite uses `#0b1224`, the page background)
- Eye: `#ffffff`
- Background: `#1e293b` (profile pic version)
